# Pipa 0.4.1

Create and customize PDF templates in a desktop editor with live PDF previews.

Version 0.4.1 is the first published release of the template workspace. The
0.4.0 build failed standalone executable smoke tests and was not published.
This release fixes bundling of CSS grammar data in standalone executables.

## Template workspace

- Edit HTML/Liquid and React PDF templates with syntax highlighting, document
  formatting, search and replace, and keyboard shortcuts.
- Resize and toggle the file, bottom, and preview panels. Browse template fields
  and jump to their references in source files.
- Organize templates into multiple files, including styles, images, and
  package-local Liquid partials. Import and export single-file templates directly
  or multifile templates as ZIP archives.
- Duplicate the built-in Classic React PDF template as an editable starting point.
  React PDF template code executes in a bounded sandbox.
- Preview with sample values, company settings, a real client, or empty data to
  test template fallbacks. Override individual fields, add and remove line items,
  and enter values for custom party fields detected in template source.
- Save complete package revisions while preserving previously generated invoices.
  Preview data changes do not modify saved company or client data.

HTML/Liquid PDF previews require the optional Gotenberg service. React PDF
previews use the built-in renderer.

## Upgrade

Docker image:
`ghcr.io/arieltl/invoice:0.4.1` (Linux amd64). Set
`INVOICE_IMAGE_TAG=0.4.1` in your `.env`, then run:

```sh
docker compose pull
docker compose up -d
```

Standalone release archives cover Windows x64, Linux x64/ARM64, and macOS
Intel/Apple Silicon. Verify downloads against `SHA256SUMS.txt`.

Back up your data before upgrading. No new database migrations are introduced
relative to 0.3.1. Existing templates remain supported. Reload the application
after upgrading to load the updated editor assets.
