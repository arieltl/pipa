# Pipa 0.3.1

Fixes generated text regressions introduced in the unified invoice workspace.

- New invoices show automatic previews for configured text generators, including
  NFS-e service descriptions, directly on the overview and in the editor.
- The editor submits the correct request identity when generating text, fixing
  rejected generation requests. Generation errors are now visible.
- Saved edits and intentionally empty text remain unchanged. Generated previews
  are not persisted until explicitly accepted and saved.

## Upgrade

Docker image: `ghcr.io/arieltl/invoice:0.3.1` (Linux amd64).
Set `INVOICE_IMAGE_TAG=0.3.1` in your `.env`, then run:

```sh
docker compose pull
docker compose up -d
```

Standalone downloads cover Windows x64, Linux x64/ARM64, and macOS Intel/Apple
Silicon. Verify archives against `SHA256SUMS.txt`.

Back up your data before upgrading. No new database migrations are introduced
relative to 0.3.0. Reopen invoice pages after upgrading to load the updated editor.
