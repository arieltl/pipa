# Pipa 0.2.0

Pipa — Personal Invoicing & Paperwork Assistant — brings configurable invoicing,
reusable text, and supporting paperwork to a lightweight self-hosted app.
This is still early-beta software: expect rough edges and back up your data.

## Highlights

- New Pipa name and kite-banknote logo, with a redesigned client settings workspace.
- Configurable client and issuer document fields, preserved in invoice snapshots.
- Revisioned PDF templates: built-in rendering plus optional Liquid HTML templates through Gotenberg.
- Per-client text generators with saved, editable output, and configurable supporting records and attachments.
- Archived invoice PDFs and append-only file storage.
- Corrected dashboard outstanding totals.
- Standalone downloads for Windows x64, Linux x64/ARM64, and macOS Intel/Apple Silicon, with SHA-256 checksums.
- Local-use, self-hosting, template, contribution, and security documentation; MIT license.

## Install or upgrade

Docker image: `ghcr.io/arieltl/invoice:0.2.0` (Linux amd64). The existing image and
executable names remain unchanged for deployment compatibility.

See the [self-hosting guide](https://github.com/arieltl/pipa/blob/v0.2.0/docs/self-hosting.md)
or [standalone executable guide](https://github.com/arieltl/pipa/blob/v0.2.0/docs/desktop.md).
Verify downloaded archives against `SHA256SUMS.txt`. Executables are unsigned;
macOS builds are not notarized. Gotenberg is optional and installed separately.

Before upgrading, stop Pipa and back up the entire data directory, including the
SQLite database and stored files. Startup applies migrations. A rollback may
require restoring the matching pre-upgrade backup. If your existing `.env` pins
an older image, change `INVOICE_IMAGE_TAG` to `0.2.0` before pulling and restarting.

## Security and limitations

There is **no built-in authentication**. Anyone who can reach Pipa can read and
change its data. Direct executable startup and Compose's published port default
to loopback; use a trusted private network or an authenticating reverse proxy
for remote access. Never expose the app directly to the public internet.

Further onboarding, template editing/preview, and configuration improvements
remain on the [roadmap](https://github.com/arieltl/pipa/blob/v0.2.0/docs/roadmap.md).
Required supporting attachments show completeness warnings but do not block
invoice issuance. Uploads are not malware-scanned. Pipa stores supporting tax
information but does not issue government tax documents.
