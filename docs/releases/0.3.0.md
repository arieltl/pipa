# Pipa 0.3.0

Pipa 0.3.0 brings a unified invoice editor, a denser invoice overview, and
in-page PDF previews. This remains early-beta software; back up your data
before upgrading.

## Highlights

- Edit document fields, notes, generated text, and supporting records on one
  continuous page with one **Save changes** action.
- See generated text and supporting field values beside the invoice, with
  convenient copy and attachment download actions.
- Preview saved PDFs and unsaved changes in a locally bundled PDF.js viewer,
  with selectable text, page navigation, zoom, and a separate download action.
- Recover interrupted saves and invoice commands through operation receipts;
  revision checks protect against stale changes from another window.
- Preserve archived PDF versions and attachment history, with guarded invoice
  issuance, status changes, and draft deletion.
- Correct outstanding totals by currency, including issued invoices, while
  keeping invoice counts and clients isolated.
- Updated documentation and screenshots using fictional demonstration data.

## Install or upgrade

Docker image: `ghcr.io/arieltl/invoice:0.3.0` (Linux amd64). The existing image
and executable names remain unchanged for deployment compatibility.

Standalone archives are available for Windows x64, Linux x64/ARM64, and macOS
Intel/Apple Silicon. Verify downloads against `SHA256SUMS.txt`. Executables
are unsigned; macOS builds are not notarized.

See the [self-hosting guide](https://github.com/arieltl/pipa/blob/v0.3.0/docs/self-hosting.md)
or [standalone executable guide](https://github.com/arieltl/pipa/blob/v0.3.0/docs/desktop.md).

1. Stop Pipa and back up the entire data directory, including SQLite and stored
   files. Keep the matching pre-upgrade backup for rollback.
2. For Docker installations, set `INVOICE_IMAGE_TAG=0.3.0` in your `.env`, pull
   the image, and restart. Otherwise replace the executable with the matching
   download for your platform.
3. Startup applies migrations for editing sessions, operation receipts, PDF
   history, and historical file ownership. If ownership is ambiguous, migration
   stops rather than guessing; restore your backup if the upgrade fails.
4. Reopen invoice pages after upgrading. Older per-card save controls are no
   longer accepted. Check an invoice and its saved PDF before resuming work.

Archived files are retained. Viewing a preview does not issue an invoice or
replace an archived PDF. Required supporting attachments remain completeness
warnings rather than issuance gates.

## Security and limitations

There is **no built-in authentication**. Keep the app on localhost, a trusted
private network, or behind an authenticating reverse proxy. Anyone who can
reach it can read and change its data.

Gotenberg remains optional and separately installed; live template editing is
not included in this release. The PDF viewer assets are served locally and do
not require a CDN. Pipa stores supporting tax information but does not issue
government tax documents.
